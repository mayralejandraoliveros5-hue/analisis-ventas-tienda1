# Análisis de ventas de una tienda utilizando Apache Spark y Kafka

## Descripción del proyecto

Este proyecto busca analizar las ventas de una tienda utilizando Apache Spark y simular el envío de nuevas ventas mediante Kafka.

## Archivos del proyecto

- **analisis.py:** realiza el análisis de los datos históricos de ventas utilizando Spark.
- **ventas.csv:** contiene los datos históricos de las ventas de la tienda.
- **simulacion.py:** permite simular nuevas ventas para observar el flujo de información.

## Objetivo

Identificar los productos más vendidos y calcular los ingresos obtenidos, con el fin de comprender el comportamiento de las ventas de la tienda.

## Instrucciones para ejecutar el proyecto

1. Instalar Python, Java y Apache Spark con PySpark.
2. Descargar o clonar el repositorio de GitHub.
3. Ubicar los archivos analisis.py y ventas.csv en la misma carpeta.
4. Abrir una terminal en la carpeta del proyecto.
5. Ejecutar el análisis con el comando:

```bash
python3 analisis.py
```

El programa procesa los datos históricos de ventas y permite analizar los productos vendidos y los ingresos obtenidos.
